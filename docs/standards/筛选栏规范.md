# 筛选栏规范

> 适用于所有列表页面的顶部筛选/搜索区域。

---

## 一、布局

使用 Arco Design `a-row` + `a-col` 栅格组件，自动换行。

```vue
<a-row :wrap="true" :gutter="[16, 12]" align="center" style="margin: 8px 0 16px;">
  <a-col flex="280px">
    <div class="filter-field">
      <label class="filter-label">标签名</label>
      <a-input v-model="keyword" placeholder="请输入" allow-clear />
    </div>
  </a-col>
  <!-- 更多筛选项... -->
  <a-col flex="auto">
    <div class="filter-actions">
      <a-button type="primary" :loading="loading" @click="handleSearch">搜索</a-button>
      <a-button @click="handleReset">重置</a-button>
    </div>
  </a-col>
</a-row>
```

### 关键属性

| 属性 | 值 | 说明 |
|------|-----|------|
| `a-row :wrap` | `true` | 允许换行 |
| `a-row :gutter` | `[16, 12]` | 水平间距 16px，垂直间距 12px |
| `a-row align` | `center` | 列垂直居中对齐 |
| `a-col flex` | `280px` | 筛选项固定宽度 |
| `a-col flex` | `auto` | 按钮列自动填充剩余空间 |
| `a-row style` | `margin: 8px 0 16px` | 上下边距（inline 确保对 a-row 生效） |

---

## 二、筛选项

### 结构

每个筛选项为一个 `a-col flex="280px"`，内部 `.filter-field` 为 flex row（label 在左、input 在右）。

### Label

- 固定宽度 `72px`，`flex-shrink: 0`
- `text-align: right`（右对齐）
- `font-size: 13px; color: var(--color-text-2)`

### 输入框/下拉框

- `flex: 1; min-width: 0`（撑满 label 之后的剩余空间）
- 所有筛选项宽度一致（280px）

---

## 三、按钮

### 顺序

搜索按钮在前，重置按钮在后。

### 样式

- 搜索：`type="primary" :loading="loading"`
- 重置：默认线框样式
- 无图标
- `min-width: 72px`（loading 状态下按钮宽度不变）

### 触发方式

- 搜索**只通过点击【搜索】按钮触发**
- 不使用 `@keydown.enter` 回车触发
- 重置通过点击【重置】按钮触发

### 位置

按钮组 `.filter-actions` 放在最后一个 `a-col flex="auto"` 中，始终跟在所有筛选项之后。

```less
  gap: 8px;

    min-width: 0;
  }
}

.filter-label {
  width: 72px;
  flex-shrink: 0;
  font-size: 13px;
  color: var(--color-text-2);
  text-align: right;
  white-space: nowrap;
}

.filter-actions {
  display: flex;
  gap: 8px;
  align-items: center;

  :deep(.arco-btn) {
    min-width: 72px;
  }
}
```
