## 详细介绍内容

### 这是什么

MokaTest 是一个面向测试团队的一站式自动化测试平台，把「质量管理 + API 测试 + UI 自动化 + 测试计划 + 团队协作」整合在同一个系统里，覆盖从需求录入到测试报告产出的完整测试流程。测试同学不需要在禅道、Postman、Selenium IDE、Jenkins 之间来回切换，一个平台即可闭环。

### 核心功能

**1. 质量管理**
- 需求池：支持 Epic/Story 层级、优先级、状态流转（草稿→评审→开发→测试→上线）
- BUG 池：严重程度/优先级/环境/重现概率全维度管理，支持评论与操作日志
- 测试用例：文件夹树管理、步骤化编写、与自动化用例双向绑定
- 血缘追踪：需求 → 用例 → BUG 的思维导图式关系图，一键看清覆盖率和质量风险

**2. API 测试**
- 接口调试：Header/Query/Body 全参数化，支持断言、提取、前后置脚本
- 参数级 Mock：可视化配置生成规则（手机号/姓名/UUID/枚举等 30+ 种），无需手写表达式
- 数据模板：可复用的结构化数据生成器，支持批量生成 1000 条并导出 JSON/CSV/Excel
- 响应定义：按结构定义自动校验响应（类型/必填/枚举/嵌套），Mock 响应自动跟随
- 多环境：环境/全局变量集中管理，一键切换

**3. UI 自动化**
- 场景可视化编排：工作流画布 + 步骤列表双视图，支持条件/循环/iframe 等复杂步骤
- 浏览器录制插件：录制操作一键导入生成场景（关注公众号「MokaTest」回复「MokaTest录制插件」获取）
- 元素库：页面元素集中管理，多场景复用
- 调试器：支持暂停/继续、断点、「执行到此步骤」，暂停期间修改步骤可热加载续跑
- AI 定位自愈：元素定位失败时，AI 分析页面快照自动推荐新定位器，真实页面验证通过后一键写回元素库

**4. 测试计划与报告**
- 手动/定时触发，支持并发执行
- Webhook 通知、多维度测试报告

**5. 团队协作**
- 团队/项目/成员三级权限隔离，角色权限灵活配置
- 站内信通知：@提及、状态变更、指派等 11 个场景，项目级可配置
- 操作日志/登录日志完整审计

### 部署方式

Docker Compose 一键部署，无需本机安装任何依赖：

```bash
git clone https://github.com/Jinglong233/MokaTest.git
cp .env.example .env
docker compose up -d --build
```

启动后访问 `http://<服务器IP>`，默认账号 `admin` / `abc123`。
